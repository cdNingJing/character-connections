接入自己的项目

当前版本提供可安装的 .tgz 组件包，尚未发布到 npm registry。

  1. 下载组件包，在自己的项目中安装： 
    npm install ./character-connections-0.7.0.tgz
  2. 选择布局和参数，下载“示例数据”，保存为 graph-data.json。
  3. 在“调用代码”中选择 TypeScript、HTML 自定义元素、React 或 Vue 3，复制代码。

组件需要明确的容器高度，只在浏览器中创建。React 在 effect 清理时销毁；Vue 在卸载时销毁。更多 API 见仓库文档。
